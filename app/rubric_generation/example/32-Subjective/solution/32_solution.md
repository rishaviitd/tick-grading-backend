# Solution for 32

**Question:** 32. The perimeter of an isosceles triangle is 32 cm. If each equal side is 5/6 of the base, find the area of the triangle.

**Question Type:** Subjective

---

**Reasoning:**
- This question has no sub-parts. It is worth 5 marks, requiring [5 to 10] steps for the entire solution. **I will strictly adhere to this step count for each method.**
- Bloom's Level: Applying.
- Assessment Intent: To assess the student's ability to translate a word problem involving an isosceles triangle's perimeter and side ratios into algebraic equations, solve for unknown side lengths, and subsequently calculate the triangle's area using geometric formulas.

**Method solution:**
- Method 1: The plan is to define variables for the sides, set up equations based on the given perimeter and side ratio, solve these equations to find the lengths of the base and equal sides, then calculate the height of the triangle using the Pythagorean theorem, and finally compute the area.
- Method 2: The plan is to define variables for the sides, set up equations based on the given perimeter and side ratio, solve these equations to find the lengths of the base and equal sides, calculate the semi-perimeter, and then apply Heron's formula to find the area.
